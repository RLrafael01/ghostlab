# Firmware real com falhas educativas declaradas

Em 28/10/2026, o usuário aprovou começar com Arduino Uno, C++ no estilo Arduino e compilação em serviço próprio, com execução no navegador. Isso preserva a relação entre programa e componentes e aceita a necessidade de conexão para compilar; AVR8js é a base proposta para a prova técnica, ainda sem validação prática.

Para permitir aprender com erros dentro do escopo inicial, as falhas terão regras educativas explícitas com consequências funcionais e visuais, em vez de depender de uma simulação elétrica de propósito geral. Dano virtual persiste até substituição ou restauração, e a explicação fica sob demanda; o produto deve declarar os limites e não apresentar esses efeitos como previsão precisa de corrente, aquecimento ou dano físico.
