# GhostLab

Laboratório eletrônico virtual 3D para montar, programar e experimentar sistemas embarcados no navegador.

Antes de alterar o projeto, leia `README.md` e `.scratch/initial-lab/spec.md`, a especificação do escopo aprovado. Para contexto e riscos da proposta, consulte `docs/PROJECT-BRIEF.md`.

## Agent skills

As skills do Matt Pocock estão em `.agents/skills/`. Leia o `SKILL.md` correspondente antes de aplicar uma delas.

### Registro de uso

Ao aplicar uma skill de Matt Pocock ou pstack, siga as convenções de `docs/SKILL-USAGE.md`. Registre o responsável e atualize os totais no PR da tarefa.

### Issue tracker

Specs e tarefas versionadas em `.scratch/`, com issues espelhadas no GitHub. Antes de implementar, corrigir, revisar ou publicar um PR, leia `docs/agents/issue-tracker.md` e atualize as issues relacionadas conforme a entrega.

### Domain docs

Contexto único: `GLOSSARY.md` e `docs/adr/`. Antes de explorar o código ou alterar termos e decisões do domínio, leia `docs/agents/domain.md`.

### pstack

Matt Pocock é o conjunto principal da atividade. A partir de agora, use também o pstack quando a tarefa se beneficiar de planejamento, verificação ou análise de impacto. Consulte `vendor/pstack/skills/<nome>/SKILL.md` antes de aplicar a skill.
